# T-strings: Safer and smarter string processing (Vinicius Ferreira)

PEP 20: There should be only one obvious way to do it.
Strings in python breaks this. There's 5 ways prior to t strings
T strings are used in the same way as f strings with have extra capabilies but look the same

T strings for jinja templates

## T strings

Introduced in Python 3.14. 
- lazy string interpolation
- we can check string before and after
- t string concat with +

## t vs f

- look the same
- f goes straight to string, cannot check before converstion

## Use cases

- Security
    - T strings can be used to escape the malicious part with harmful code
    - Libraries have already started using t strings
- Domain Specific Languages
    - Can shorten code into smaller lengths by handing some of the logic themselves
- Logging
    - Split logging into human readable logging and machine readable logging

## Drawbacks

- No automatic string output, (probably boiler plate looking code), DRY would need to be implemented
- Performance? He didn't know but its worse than fstrings, trade speed for security
- Complexity/UX
- Partial standardization: Its python so there will be lots of different ways they can be implemented.
